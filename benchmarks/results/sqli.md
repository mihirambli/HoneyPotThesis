ALERT / TRAP lines per request must be 1 / 0 for a hit and 0 / 1 for a miss on a WADM tier: a hit that logs no ALERT is a missed detection, a miss that logs an ALERT a false positive. Reconnects: the share of requests that opened a new connection — Apache closes the connection after every 500, so on Apache every hit costs the client a reconnect.
