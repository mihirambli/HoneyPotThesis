# Proxy deployment against in-server deployment

Generated by `benchmarks/compare_deployments.py`. Every figure is a **paired difference measured inside one session** (median of the per-replicate differences, with their range across replicates in brackets; `spans 0` = the range includes zero). The two deployments were measured in **separate sessions**, so they are compared as two paired differences, never by subtracting raw latencies across sessions. *Overlap* says whether the two ranges overlap: `no` means the deployments differ by more than either session's replicate spread; `yes` means this harness cannot order them.

Latency is per GET (mean of the four GET probes within a replicate) in microseconds. CPU is microseconds per request: for the module cost, of the host container (the server running the module); above the origin, of the stack (host container + origin container; on the origin tier only the origin serves).
