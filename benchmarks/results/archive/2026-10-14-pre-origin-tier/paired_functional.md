Generated by `benchmarks/plot_paired_overhead.py`. Every measured response is compared with the response the same edge returned before the load started (`intact` = status and body hash identical). Before the load, each probe is also sent to the origin directly: the bare tier must return exactly what the origin returns, and the WADM tiers must carry the bait header, cookie and comment on every proxied probe. Alert recall is alert lines logged in the measured window ÷ the lines the probes should trigger (7 ALERT and 2 TRAP per iteration); on bare it is the raw count, which must be 0. *Timing lines* is the most any cell of that tier logged: it must be 0 on bare and silent, which is the check that the tier switch did what it says.
