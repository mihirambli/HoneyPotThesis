# Latency above the origin floor (paired dataset)

Generated by `benchmarks/plot_origin_floor.py` from `paired_<edge>.json`. The origin tier sends the same probes as every other tier straight to the origin, with the edge idle, inside the same replicate, so each difference below is paired: measured minutes apart and summarised as the median over replicates, with the replicate range in brackets. *WADM* is the deployed build (no benchmark timing lines). µs per GET is the mean of the four GET probes' median latencies; the SQLi POSTs are excluded because the origin has no trap. ‡ = the replicates disagree in sign, so the difference is below what this harness resolves; † = too few replicates (under 3) to judge, as in a smoke run.
